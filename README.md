# student_management_system
Student Management System (C++98)

A console-based Student Management System developed using Object Oriented Programming (OOP) concepts in C++.
Features:
---------
Add student records
View all students
Search students by ID
Grade calculation
Menu-driven interface

Concepts Used:
-------------
Encapsulation
Inheritance
Polymorphism
Abstraction

Classes Used:
-----------
1. Person
Base class
Stores common attributes: id, name
Provides virtual function display()
2. Student (inherits Person)
Stores student-specific details: course, marks
Implements grade calculation
Overrides display() method
3. StudentManager
Manages student records
Handles operations:
Add student
View students
Search student

Technologies:
------------
Language: C++ (C++98)
Data Structure: vector
